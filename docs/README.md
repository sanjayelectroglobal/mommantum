## Core Guidelines
- Any change to architecture, data models, or routes must be reflected in `architecture.md` and `memory.md`.
- Every feature or modification requires an approved task plan in `task.md` before coding begins.
- Private local working rules are preserved in `.workrules/RULES.md`.
